# AI Company OS

AI Company OS is an AI-powered operating system for running a company through a coordinated hierarchy of AI agents.

## Documentation

The authoritative specifications reside in the `docs/` directory:
- [PRD.md](docs/PRD.md): Product requirements, goals, and capabilities
- [Architecture.md](docs/Architecture.md): System architecture, boundaries, data flows
- [Rules.md](docs/Rules.md): Mandatory engineering, security, and reliability rules
- [Phases.md](docs/Phases.md): Development roadmap and implementation order
- [UI.md](docs/UI.md): Frontend structure, design tokens, and user experience
- [Memory.md](docs/Memory.md): Work state, persistence, and memory architecture
- [IMPLEMENTATION_STATUS.md](IMPLEMENTATION_STATUS.md): Comprehensive implementation records across all completed phases

## Current Status

- **Completed Phases:** Phase 0 through Phase 22 (Verification & AI Evaluation)
- **Live Meeting Room:** Interactive AI Agent Meeting Room (`/meeting`) with 3D Holographic Canvas Orb, voice command interface, real-time equalizer, and live portfolio capabilities.
- **Next Phase:** **Phase 23 — Security Hardening** (Awaiting authorization per `docs/Phases.md` § 27).
